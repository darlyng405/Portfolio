02Trabajo Seleccionado
SIA — Sistema de Información Académica
Plataforma de Gestión Académica Multi-rol
En Producción GitHub
// EL PROBLEMA

La institución necesitaba una plataforma centralizada para gestionar procesos académicos, usuarios y reportes.

// MI SOLUCIÓN

Diseñé y desarrollé un sistema multirol para administradores, docentes, estudiantes, coordinación y orientación. Implementé autenticación JWT con middleware propio, bcrypt y rate limiting. Generé reportes PDF dinámicos con PDFKit y cobertura de API con tests automatizados (Jest + Supertest).

// STACK
Node.jsExpressPostgreSQLSQL ServerJWTJestPDFKit
// RESULTADO
  • Sistema actualmente en producción y utilizado dentro de la institución.
  • Autenticación robusta con bcrypt y protección contra fuerza bruta.
  • Reportes PDF dinámicos y API completamente testeada.
Votech — Plataforma de Votación
Backend de Votación Digital en Tiempo Real
Completado GitHub
// EL PROBLEMA

Se necesitaba una plataforma confiable para gestionar votaciones durante una feria tecnológica con alta concurrencia.

// MI SOLUCIÓN

Desarrollé el backend completo en TypeScript con Express y Supabase, implementando autenticación JWT propia desde cero, CORS restrictivo por entornos y una API REST con módulos de proyectos, votos y resultados.

// STACK
TypeScriptNode.jsExpressSupabaseJWTbcrypt
// RESULTADO
  • La plataforma soportó ~500 usuarios durante el evento sin interrupciones ni fallos.
  • API REST escalable con integridad de votos garantizada.

04Mi Proceso
[01]
Comprender el Problema
Antes de escribir código, busco entender qué necesidad existe realmente y quién utilizará la solución. Primero entiendo, luego código.
[02]
Diseñar una Arquitectura Simple
Prefiero sistemas claros, mantenibles y escalables antes que soluciones excesivamente complejas. Los edge cases me quitan el sueño (literalmente).
[03]
Construir e Iterar
Desarrollo funcionalidades, recibo retroalimentación, identifico problemas y realizo mejoras continuas. No copio soluciones sin entenderlas.
[?]
Resolución de Problemas
Descompongo problemas complejos en partes manejables. Aprendí a construir sistemas reales antes de terminar el colegio.
[~]
Comunicación Técnica
Puedo explicar arquitecturas complejas de forma clara. Los logs son para personas, no para máquinas.
[+]
Criterio Técnico
Si no sé por qué funciona, no lo uso en producción. Me adapto al problema, no al revés.
